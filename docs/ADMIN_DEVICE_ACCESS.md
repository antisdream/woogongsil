# 관리자 접근

확인일: 2026-09-09 · 소스 버전: 2.4.4

## 로그인 방법

1. `/manage`에서 관리자 아이디 `skn29`와 기존 사이트 비밀번호를 입력합니다.
2. 계정에 등록된 이메일로 받은 6자리 숫자를 5분 이내에 입력합니다. 수신 주소는 일부를 가려 표시하며 화면에서 변경할 수 없습니다.
3. `인증하고 로그인`을 누르면 관리자 세션이 발급됩니다. 메일이 보이지 않으면 스팸함을 확인하고, 60초 후 재전송할 수 있습니다.

재전송 시 이전 번호는 만료됩니다. 15분간 최대 5회 발송하며, 인증번호를 5회 틀리면 15분 후 다시 로그인해야 합니다. 발송과 오입력 제한은 계정 단위 DB에 기록하므로 새 브라우저나 서버 재시작으로 초기화되지 않습니다. 발송 실패·만료 상태를 화면에 표시하고 재전송할 수 있습니다. 인증 대기는 최초 비밀번호 확인부터 최대 15분이며 새로고침 시 복구됩니다.

## 적용 정책

로그인 화면은 누구나 인증서 없이 열 수 있습니다. `skn29`만 허용하며 비밀번호·관리자 권한·정지 상태를 검증합니다. OTP 단계에서도 권한과 등록 이메일·비밀번호 변경 여부를 다시 확인합니다. 번호까지 확인하기 전에는 관리자 권한이 없습니다. 2차 인증 도입 전에 발급된 관리자 세션은 다시 로그인해야 합니다.

인증번호는 암호학적 난수로 생성합니다. HttpOnly·SameSite=Strict 임시 쿠키와 HMAC으로 연결하며, DB에는 코드와 쿠키 원문을 저장하지 않습니다. 운영 쿠키는 Secure이고 모든 인증 응답은 no-store입니다. Origin·CSRF 검증, 세션 만료·폐기, 관리자 API 보호와 기존 내부 결재 재호출 검사는 유지합니다. 메일 본문·번호·수신자를 로그에 출력하지 않으며 SMTP 연결·응답에 시간 제한을 둡니다.

기존 `MAIL_USER`, `MAIL_APP_PASSWORD` SMTP 설정을 사용합니다. 수신 주소는 `wgs_users`의 `skn29` 이메일입니다. 코드·환경 예시나 릴리즈에 실주소·비밀번호를 넣지 않습니다. 이메일 계정에 접근할 수 있어야 로그인할 수 있으므로 등록 이메일을 변경할 때 수신 가능 여부를 확인합니다. 이메일 인증은 기기 소유나 피싱 방지 인증을 증명하는 방식은 아닙니다.

2.4.2의 기기 인증서 제한은 취소된 상태를 유지합니다. Windows·휴대폰 인증서 설치나 선택이 필요하지 않습니다. 홈페이지에는 관리자 링크를 표시하지 않습니다.

## 배포와 복구

소스만 선별해 커밋·푸시하고 서버 앱·DB·설정 전체 백업과 체크섬을 검증한 뒤 정식 GitHub 릴리즈를 발행합니다. 시작 시 OTP 상태 테이블과 기존 관리자 세션의 인증 일시 열을 추가합니다. 기존 회원 데이터는 다시 쓰지 않습니다. Nginx·OS·기기 인증서 설정 변경은 필요하지 않습니다.

배포 후 버전·커밋 일치, 로그인 HTML 200, 비로그인 관리자 API 및 OTP 제출 거부, 신규 스키마·메일 설정과 서버 로그를 확인합니다. 배포 시스템은 실패 시 직전 소스·화면을 복원합니다. 추가 테이블·열은 이전 소스와 호환되므로 복구 시 삭제하지 않습니다. 이전 2.4.3으로 복구하면 이메일 인증 요구도 이전 정책으로 돌아갑니다.

## 확인한 범위

- 백엔드 144개, 프런트엔드 22개, 배포·복구 8개 검사와 린트·프로덕션 빌드 통과.
- 실제 임시 MySQL·Express·bcrypt 및 빌드된 화면 검사 77개 통과: 중복 인증 1회 성공, 동시 오입력 5회 잠금, 서비스 재생성 후 상태 복구, 코드 만료·재전송·메일 발송 실패, 기존 세션 테이블 전환 포함.
- 320·412·1440px에서 실제 테마 버튼으로 밝은/어두운 화면, 가로 넘침, 새로고침 후 인증 재개, 오입력 안내·정상 인증·로그아웃 확인. 브라우저 실행 오류 0개.
- 로컬 로그인 계정과 메일 수신은 시험 데이터이며 운영 DB와 실제 운영 비밀번호를 사용하지 않았습니다. 운영 SMTP 인증 성공은 실제 받은편지함 수신이나 운영 로그인 완료를 대신하지 않습니다.
- 일반 회원 로그인·비밀번호 찾기·방문 통계 및 Android 네이티브 소스는 이번 인증 변경 범위가 아닙니다. APK를 새로 빌드하지 않았습니다.
