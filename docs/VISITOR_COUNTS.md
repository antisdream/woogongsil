# 웹·APK 방문 통계

확인일: 2026-09-09 · 소스 버전: 2.4.1

## 표시와 집계

- 일반 웹과 Android WebView의 공통 하단에 `오늘 방문`과 `누적 방문`을 표시합니다. 관리자 탭이나 특정 화면을 열어야 집계되는 구조가 아닙니다.
- 수치는 기존 `wgs_visit_sessions`의 제외되지 않은 방문 횟수입니다. 같은 브라우저의 활성 방문은 이어가고 기본 5분 이상 활동이 끊기면 새 방문이 시작됩니다. 브라우저·앱 설치별 저장소가 달라 같은 사람이 여러 환경에서 방문할 수 있으므로 고유 인원수가 아닙니다.
- 오늘 방문은 한국시간으로 방문을 시작한 날짜를 기준으로 합니다. 자정을 지나 계속 사용 중인 방문은 시작일에 속하며, 새 방문이 시작되면 새 날짜에 집계됩니다. 누적에는 기존 방문·로그인 이력에서 이전에 반영된 기록도 포함합니다. 이번 변경으로 과거 데이터를 다시 생성하거나 초기화하지 않습니다.
- 페이지 이동·새로고침·동시 요청은 활성 방문을 중복 생성하지 않습니다. 숨겨진 화면이나 오프라인 상태에서는 heartbeat를 보내지 않고, 화면 복귀·재접속 때 재개합니다. 봇·모니터링과 관리자 제외 정책은 유지합니다.

## API와 갱신

`POST /api/visitors/visit`는 방문을 기록하고 `success`, `counted`, `ignored`, `reason`만 반환합니다. `GET /api/visitors/summary`는 읽기 전용이며 아래 항목만 공개합니다.

```json
{"success": true, "todayCount": 12, "totalCount": 375}
```

개인별 방문 경로·회원 정보·로그인 시각은 공개 응답에 포함하지 않습니다. 관리자 상세 API는 계속 인증을 요구합니다.

화면이 보이는 동안 60초 간격으로 기록·조회합니다. 서버 합계 캐시는 30초, 브라우저의 중복 조회 캐시는 15초이며 한국시간 날짜 변경 시 이전 날짜 캐시를 재사용하지 않습니다. 다른 방문의 증가가 즉시 보이는 실시간 접속자 수는 아닙니다. 연결 실패나 잘못된 응답은 `0`으로 바꾸지 않고 대시로 표시하며 재시도합니다.

| 웹 품질 검사 | 통과 | ESLint와 프로덕션 빌드 |
| 배포 검사 | 6/6 | 공개 합계 이상 시 배포 검증 실패 및 기존 복구 경로 |
| Android | 16/16 | 단위검사, debug APK 생성, Lint 오류 0개 |

Android Lint 경고 4개는 targetSdk, lifecycle 의존성 버전, Compose Modifier 인자 순서, v26 리소스 폴더 관련 기존 항목입니다. 이번 작업에서 SDK·라이브러리·네이티브 UI 범위를 넓히지 않았습니다. 실제 기기는 연결되어 있지 않아 이번 버전의 실기기 화면·재개 동작은 재검증하지 않았습니다.

기본 debug/internal/release APK는 운영 웹을 로딩하므로 서버에 반영된 하단을 사용합니다. `Build-LocalWebDebug.ps1`로 예전 웹 파일을 포함한 APK는 새 웹으로 빌드·설치해야 합니다. 앱 버전이나 빌드 통과를 Google Play 출시 검증으로 해석하지 않습니다.

배포는 로컬 확인 → 지정 경로 커밋·푸시 → Lightsail의 앱·DB·설정 전체 백업 및 검증 → GitHub 정식 릴리즈 순서입니다. 배포 후 `/version.json`, 공개 합계와 인증 경계를 확인합니다. 백업 파일과 운영 비밀값은 저장소·릴리즈 첨부에 넣지 않습니다.
