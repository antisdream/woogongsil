# 우공실 v2.4.7 앱·웹 랜딩 애니메이션 검증

작성일: 2026-09-10

## 적용 범위

사용자가 선택한 앱 2안과 웹 3안을 홈의 학습 미리보기에 적용한다.

| 접속 환경 | 표시 방식 |
| --- | --- |
| 설치된 우공실 Android 앱 | 2안: 문제 선택, 정답 WHERE의 이동, 해설, 오답 복습으로 이어지는 9초 학습 흐름 |
| PC 웹·태블릿 웹·휴대폰 브라우저 | 3안: 학습 노트의 두 책장과 문제·해설·복습이 이어지는 8초 애니메이션 |

기존 네이티브 User-Agent의 `WoogongsilAndroid/0.1` 표식으로 표시 방식을 고른다. 화면 폭이나 일반 Android·WebView 표식으로 앱을 판단하지 않으며, 이 분기는 화면 표시용이다.

홈 미리보기 컴포넌트와 전용 스타일, 분기 검사, 버전 및 이 문서·변경 이력만 변경한다. 기존 수동 SQL 예제를 그대로 감싸서 제공하며 제목·설정 문구·배너·학습 시작 경로·FAQ는 유지한다. 서버·DB·인증·학습 채점·Android 네이티브 코드는 변경하지 않는다. 의존성을 추가하지 않는다.

## 사용 동작

- 기존 화면 설정의 라이트·다크 테마와 밝기를 사용한다.
- `일시정지`와 `재생`으로 애니메이션을 제어한다.
- `직접 풀어보기`에서 기존 SQL 예제를 풀고, `애니메이션 보기`로 돌아올 수 있다. 전환하는 동안 선택·정답 해설을 유지한다.
- 설명용 애니메이션과 예제 결과는 학습 기록에 저장하지 않는다.
- 화면 밖·다른 화면·앱 백그라운드에서 애니메이션을 멈추고 표시될 때 재개한다.
- 시스템 `동작 줄이기`가 켜져 있으면 정지 화면과 안내를 표시하며 수동 예제는 계속 사용할 수 있다.

## 로컬 검증

| 검사 | 결과와 범위 |
| --- | --- |
| 프런트엔드 전체 ESLint | 통과 |
| 프런트엔드 Node 검사 | 27/27, 앱·모바일 웹·일반 WebView·잘못된 표식 분기 포함 |
| Vite 프로덕션 빌드 | Node 22.22.2에서 통과 |
| Chromium 브라우저 검사 | 192/192 |
| Android 단위 검사 | 16/16 |
| Android APK 빌드·서명 검증 | 통과, 이전 설치 앱과 동일 서명 |
| Android Lint | 오류 0개, 기존 경고 5개 |
| Z Flip4 후보 APK | 25/25, 2.4.7-mobile-ui / versionCode 20407 |

브라우저 검사는 실제 프로덕션 프런트엔드 빌드와 운영 공개 화면 설정을 바탕으로 만든 로컬 API 응답을 사용했다. 1440·1024·412·320px, 앱 표식 유무, 두 테마, 글자·터치 영역·가로 넘침, 재생 시간·정지·재개, 직접 풀이의 오답·정답·다시 풀기·전환 보존, FAQ·로그인 시작 경로·뒤로 가기, 동작 줄이기를 확인했다. JavaScript 예외·콘솔 오류·예상하지 않은 API 요청은 없었다. 이 결과는 운영 계정 로그인을 수행했다는 뜻이 아니다.

실기기 검사는 Galaxy Z Flip4(SM-F721N), Android 16, WebView 152, CSS 화면 폭 360px에서 수행했다. 데이터 초기화 없이 `adb install -r`로 업데이트한 앱에서 실제 터치, 두 테마, 수동 오답·정답, Home 키로 백그라운드 이동·복귀, Android Back, FAQ·빈 로그인 화면, 실제 번들 응답의 파일 해시를 확인했다. 학습 제출 API를 호출하지 않았고 화면 검사로 발생한 쓰기는 기존 방문 집계뿐이다.

검사 기기의 시스템 `동작 줄이기`는 켜진 상태였다. 이 상태의 정지 화면을 확인한 뒤 WebView 디버깅 세션에서만 미디어 설정을 임시 전환해 애니메이션을 검사했으며, 종료 시 시스템 기본 동작과 기존 테마를 복원했다. 설정을 켠 기기에서는 배포 후에도 기본 화면이 정지 상태로 표시된다.

WebView의 프레임 캡처에서 일부 움직이는 글자가 세로로 눌려 보였다. 동일한 화면을 Android 자체 캡처로 대조했을 때 실제 표시는 정상임을 확인했다. 최종 기기 화면의 시각 확인은 Android 자체 캡처를 기준으로 한다.

Android Lint의 기존 경고는 `OldTargetApi`, `GradleDependency` 2개, `ModifierParameter`, `ObsoleteSdkInt`다. Play 스토어 배포·결제·여러 제조사 기기 검증은 이 변경의 확인 범위에 포함하지 않는다.

## 변경 보존과 배포

기준 main은 `5c04afc9d243aa99a7c6f632dd96d6b5b2789bb0`이며 별도 작업 트리에서 작업했다. 원래 작업 폴더의 405개 파일 내용과 삭제 상태, HEAD·index·미커밋 상태가 그대로임을 해시와 Git 상태로 확인했다.

로컬 검증을 통과한 소스를 `2026-09-10|작업내용` 형식의 한글 커밋으로 푸시하고, 정식 v2.4.7 릴리즈의 기존 자동 배포 절차를 사용한다. 운영 전환 뒤 공개 버전·커밋과 릴리즈 번들을 대조하고, 실제 배포 웹 파일을 포함한 최종 APK를 다시 만들어 같은 서명으로 업데이트한다.

배포 후 결과는 실행이 끝난 뒤 이 문서에 추가한다.
