# 우공실 v2.4.8 랜딩 자동 재생 수정·검증

작성일: 2026-09-10

## 요청과 확인된 원인

웹에서는 움직이지만 연결된 휴대폰에서는 랜딩이 멈춘다는 제보를 확인하고, 선택 버튼 없이 자동으로 움직이는 랜딩으로 변경한다. 설치 앱의 2안과 PC·휴대폰 웹의 3안은 유지한다.

수정 전 실제 Galaxy Z Flip4(SM-F721N), Android 16, WebView 152, `2.4.7-mobile-ui / 20407`에서 아래 상태를 재현했다. 시스템 설정이나 WebView 미디어 조건은 바꾸지 않았다.

| 수정 전 측정 | 결과 |
| --- | --- |
| 페이지 표시 | `document.hidden=false` |
| 시스템 동작 줄이기 | `prefers-reduced-motion: reduce=true` |
| 랜딩 실행 상태 | `data-motion-running=false` |
| 실제 장면 애니메이션 | 0개 |
| 카드 애니메이션 이름 | `none` |
| 공통 스타일의 주기 | `1e-05s` = 0.01ms |

원인은 `HomeHeroMotion`의 시스템 설정에 따른 재생 차단, 전용 CSS의 `animation:none`, 공통 디자인 시스템의 `.01ms` 축소 규칙이다. 이전 버전은 이 설정을 따르는 구현이었으며, 이번 요청에 맞춰 홈의 설명용 애니메이션을 자동 재생 전용으로 바꿨다.

## 수정 범위

- `HomeHeroMotion.jsx`: 사용자 재생·정지 상태, 시스템 설정에 따른 차단, 수동 예제 전환을 제거했다. 화면 표시·백그라운드 상태에 따라 자동으로 멈추고 재개한다.
- `HomeHero.jsx`: 랜딩의 수동 SQL 예제 컴포넌트를 제거하고 자동 애니메이션만 표시한다. 실제 학습 기능은 변경하지 않는다.
- `home-hero-motion.css`: 선택 버튼·정지 장면 스타일을 제거했다. 홈 장면 안에서만 공통 축소 규칙보다 우선하여 앱 9초·웹 8초 주기를 유지한다.
- 버전·변경 이력·이 검증 문서를 갱신한다.

기기 설정, Android 네이티브 코드, 공통 디자인 시스템, 서버·DB·인증·학습 채점, 의존성은 변경하지 않는다. 기존 제목·문구·학습 시작 경로·FAQ·테마·다른 화면의 동작 줄이기는 유지한다. 자동 장면의 예시는 실제 기록으로 저장되지 않는다.

브라우저 검사는 실제 빌드와 운영 공개 화면 설정을 기반으로 한 로컬 API 응답을 사용했다. PC 1440px, 모바일 웹 412·320px, 앱 표식 360·320px에서 두 테마와 시스템 동작 줄이기 유무를 나눠 확인했다. 자동 재생·정상 8/9초 주기·버튼 및 수동 예제 부재·가로 넘침·책장 글자 배치·화면 밖 정지·복귀·FAQ·빈 로그인 화면·뒤로 가기·기존 문구와 테마를 검사했다. 다른 화면의 공통 축소 규칙도 그대로임을 확인했다. JavaScript 예외·콘솔 오류·예상하지 않은 API는 없었다.

검증 도구가 순간적인 테마 색상 전환을 반복 애니메이션과 함께 측정하는 문제를 수정하여, 반복 주기는 `CSSAnimation`만 측정하고 정지 적용 완료를 기다린다. 앱 소스 변경 없이 최종 검사를 통과했다.

실기기에서는 시스템 `동작 줄이기=true`를 그대로 유지했다. WebView 미디어 조건을 바꾸거나 애니메이션을 강제로 재생·특정 위치로 이동하지 않았다. 실제 터치로 두 테마를 확인하고, 시간 경과에 따른 재생 시간·화면 변형·Android 자체 캡처를 대조했다. 후보의 연속 측정에서 9초 애니메이션 시간이 약 6,692ms에서 17,906ms로 진행되어 다음 주기로 이어졌다. 화면 밖·Home 키로 백그라운드 이동·복귀, Android Back, 기존 FAQ·빈 로그인 경로도 통과했다.

앱을 완전히 종료한 뒤 `am start -W`의 `LaunchState: COLD`를 확인했다. 화면을 누르거나 스크롤하지 않고 재생 시간이 약 794ms에서 1,704ms로 진행됐고 `running=true`, 주기 9초, 선택 요소 0개를 확인했다. 시스템 동작 줄이기는 여전히 켜져 있었다. 기기 테마는 검사 뒤 원래 값으로 복원했다.

Android Lint의 기존 경고는 `OldTargetApi`, `GradleDependency` 2개, `ModifierParameter`, `ObsoleteSdkInt`다. 운영 계정 로그인·학습 제출, Play 스토어 배포와 다른 제조사 기기는 이번 검사에 포함하지 않는다.
